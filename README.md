# 📚 LibraryManagement.Api

### Progresso 1
Nesta missão criei a estrutura inicial da Web API utilizando ASP.NET Core.

Crie um BooksController, utilizei atributos como [ApiController], [Route], [HttpGet] e [HttpPost].

Aprendi sobre Actions, ControllerBase, IActionResult, Ok(), Created(),Model Binding e o retorno de objetos como JSON.

Também utilizei o Swagger para testar os endpoints da API.

---
### Progresso 2
Nesta missão implementei o CRUD de livros na API, trabalhando com os métodos HTTP GET, POST, PUT e DELETE. 

Criei o endpoint para buscar um livro pelo ID utilizando Route Parameters e aprendi a trabalhar com [HttpGet("{id}")].

Aprendi a utilizar NotFound(), BadRequest() e NoContent().

Ao finalizar esta missão, a API passou a possuir um CRUD completo de livros funcionando em memória.
